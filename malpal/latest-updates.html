Version 1.1.0 2026/11/17

A major update introducing new profile and anime page stats, an in-page update notification banner, clearer option wording, and refreshed pop-up colors.

New Features

  • Show Account Age in Years: Displays how many years ago a user created their account next to their join date on user profiles.
  • Show Airing Run Duration: Displays how long an anime has been airing (or aired) next to its Aired date in the Information Panel.
  • Update Banner: Displays a non-invasive banner directly on MAL when the extension updates. It matches native MAL styling, respects existing MAL announcement banners, and stays hidden once dismissed until the next update.

Improvements & Fixes

  • Wording & Color Updates: Rewrote option titles and descriptions across nearly every setting in the pop-up for clarity and updated colors for a cleaner look.
  • Pop-up Polish: Rounded out the bottom option and description panel when expanded, updated watch length text classes, and improved compatibility with latest Firefox version.
